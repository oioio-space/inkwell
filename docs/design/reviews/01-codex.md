# Revue Codex n°1 du système de design (2026-11-01) — verdict : revise

§2.2 [M] Recalcul [WCAG 2.2](), composition sRGB sans arrondi intermédiaire : sur `--view-bg` sombre, warning = **10,48**, erreur = **7,85**, contre 9,88/7,40 annoncés ; personne-4-line sur blanc = **3,14**, contre 3,05. Les minima déclarés restent satisfaits sur leurs fonds de calcul.
§2.2 [M] Les fonds translucides n’ont pas de fond parent déclaré dans `contrast` : warning/texte blanc = **9,76** sur headerbar sombre, contre 11,45 ; différences ajout/suppression sur window = **7,96/7,51**, contre 8,46/7,96 calculés sur view. §4.6 annonce aussi 12,57 dans les deux thèmes, contrairement au JSON.
§2.2, §7 [B] Paires d’états oubliées : `--fg-dim` sur sélection claire = **4,48** sur view, **4,26** sur sidebar ; `HistoryRow.svelte:158` utilise ce texte sur sélection. Les numéros de ligne (`editor/setup.ts:40`) donnent **2,51** sur blanc : omissions de l’inventaire.
§2.1 [M] `tokens.json` ne pilote pas intégralement CSS : `--hl-link` absent, variantes `--person-N-line` seulement en prose, dimensions sans mapping CSS, HC encodé avec `|`, typographies « raccourci font » sans famille. Le test actuel vérifie seulement neuf couleurs syntaxiques ; README et description JSON présentent à tort la parité comme existante.
§4.16, §5.5 [B] L’inventaire manque une rupture du parcours principal : `App.svelte:197` fournit `onOpen={() => session.focus()}` ; `Sidebar.svelte:50` transmet pourtant le chemin. Cliquer un fichier ne déclenche aucune ouverture.
§3.4, §4.19 [M] Les références fichier:ligne contrôlées correspondent généralement au code, mais G-16 oublie la **troisième** source de toasts (`ui/sheet/Sheet.svelte:605`, minuterie indépendante à :169), ainsi que ses bandeaux locaux de filtre, détection et échec (:468–554). Leur migration doit être explicitée.
§4.3–4.5, §4.16, §4.22 [M] Écarts clavier toolbar/tabs/tree confirmés dans FormatBar, HistoryDrawer et Sidebar. Autres omissions : toolbar du tableur (:479), radios de Preferences (:52), DiffView (:181) et HistoryBars ; l’historique est un **listbox**, contrairement au `list` annoncé, et ses flèches changent la sélection sans déplacer le focus ni renseigner `aria-activedescendant`.
§4.2, §4.13, §4.24 [M] `MenuButton.svelte:115` ouvre aussi par ↑ sur le premier élément ; l’exception Échap→éditeur reste contraire au retour attendu du [menu APG](). Remplacer un select de huit options par un menu change le modèle de sélection ; la palette omet explicitement `aria-expanded`, `aria-controls`, `listbox/option` et `aria-selected`.
§4.8–4.9 [M] Preferences (:38) et AboutDialog (:62) forcent le retour à l’éditeur ; PeopleDialog (:160) ouvre une confirmation sans gestion locale du focus ni d’Échap. Le futur composant doit couvrir ces comportements, et adapter le focus initial aux longues comparaisons conformément au [dialogue APG]().
§4.11–4.12 [B] La consigne « texte avant apparition de la région » inverse le montage fiable : établir la région puis mettre son contenu à jour ([ARIA22]()). `NoticeToast.svelte:6` monte actuellement région et texte ensemble ; une annonce effective reste à vérifier avec lecteur d’écran.
§3.4, §4.12, §7 [B] Pause au survol/focus après découverte ne suffit pas à garantir [2.2.1]() : prévoir désactivation du délai ou accès durable à Annuler. Un bandeau permanent prioritaire peut aussi masquer indéfiniment les suivants, dont le seul accès alternatif est seulement DEVRAIT (§4.15).
§1, §3, §5 [M] Arbitrages manquants : T11 A6 impose l’aperçu superposé sous 900px, §3.3 le conserve côte à côte ; T11 B10 place Sommaire/Tâches à gauche, L-2 impose le tiroir et omet Sommaire. §4.22 conserve « variantes » malgré « brouillon » au glossaire ; L-10 propose Annuler après un retrait pourtant déclaré irréversible.
§10 [M] Toutes les règles n’ont pas de preuve définie : le lint Svelte manque les styles CodeMirror en TS ; mesurer seulement les boutons à 24px ne vérifie ni champs, ni cibles 34/44px ; une capture ne prouve pas les annonces. Ajouter une traçabilité règle→assertion, incluant états concurrents et fonds composés.
