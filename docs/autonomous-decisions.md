| 2026-11-12 | PB | The absolute p95 budget (≤ 400 ms, judged on the 80th of 80 samples) failed only on background bursts (gortex 400–490 % CPU every 6.5 s; ~7 % of starts at 430–640 ms on reference and change alike). Threshold unchanged. Amends ADR 0038's invalid-run rule to per-sample | the order statistic that certifies a p95 is the maximum, so it measures interference, not the app; ADR 0038 already says environmental faults invalidate, this applies it per sample | raising the limit (weakening), dropping the p95 budget, stopping the user's tools |
| 2026-11-12 | PB | Threshold for an interfered start: 1.5 CPUs of other processes' CPU during the start window, derived from four archived A/A runs (640 starts, `docs/perf/2026-11-12-start-bg/`): every start over 400 ms is above it, every start at or below it is ≤ 370 ms; model false failure ≤ 1e-3. Measured invalid share 17.7–19.5 % against the 20 % cap: a run over the cap is invalid and retried, never passed. | Derived from measurement and the model, not tuned to pass; the cap stays below the 30 % detached-helper mutant it must reject. | A relative bound (ambient load estimated per run, follow-up F6) — more robust on a busier host, filed; raising the cap — would let the detached-helper mutant through. |
| 2026-11-12 | PB | Independent review said "fix first": the process-tree CPU accounting lets a detached helper hide a tail regression, and app-induced system work biases discards. Fix: each start in its own cgroup (app CPU from `cpu.stat`), an exact per-side test on discarded starts (imbalance → fail), model run at the shipped 1.5 bound, plus refbuild hardening (dirty tree fails, one build vector, full cache key, `-buildvcs=false`). The 2026-11-12 amendment is accepted under the autonomy rule, made sound by these two checks rather than by a looser bound. | A covariate filter is only exact if discards are label-independent; the cgroup and the imbalance test make that checkable instead of assumed. | Keep the process tree (unsound against setsid); drop the per-sample filter and raise the p95 budget (weakens the gate). |
