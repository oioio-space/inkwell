## Wails v3.1.0 — WAILS1

- **WindowClosing and WC1.** The tagged Go source retains `RegisterHook`, event cancellation and the common event emitted by `Close()`. WC1 cancels the first request and consumes the later close permit in `cmd/inkwell/desktop_close.go:31`. Its cleanup listener starts at line 42. The desktop backend changes and application-event ordering fixes in 3.1.0 warrant replaying the native GTK close, save failure and retry, and reopen proof in `cmd/inkwell/wc1_native_test.go:596`. Run the equivalent native close smoke on other shipped platforms before claiming support there. [Tagged hook](https://github.com/wailsapp/wails/blob/v3.1.0/v3/pkg/application/webview_window.go#L1007), [tagged Close](https://github.com/wailsapp/wails/blob/v3.1.0/v3/pkg/application/webview_window.go#L1287), [release](https://github.com/wailsapp/wails/releases/tag/v3.1.0).
- **Streams.** The Go Stream files and desktop runtime `src/stream.ts` are byte-identical between the versioned Go archives. The upgrade still changes the host around them, including WebView2 request-body handling, escaping in service routes and embedded runtime asset generation. Inkwell registers net/store/preview/lsp/present at `cmd/inkwell/main.go:180` and its close stream at `cmd/inkwell/desktop_close.go:49`, where it also checks stream ownership. The real frontend consumers include `frontend/src/workspace/workspace.svelte.ts:478`, `frontend/src/workspace/workspace.svelte.ts:494` and `frontend/src/App.svelte:425`. Bump all three version pins together (`go.mod:20`, `mise.toml:32`, `frontend/package.json:30`) and replay binary payloads, reconnect and window ownership in the native webview. The bridge continues to use Wails Streams without a desktop loopback listener. [Tagged Stream implementation](https://github.com/wailsapp/wails/blob/v3.1.0/v3/pkg/application/stream.go), [runtime bundling change](https://github.com/wailsapp/wails/pull/6458), [WebView2 body fix](https://github.com/wailsapp/wails/pull/6326).
- **GTK4 build selection.** GTK4 and WebKitGTK 6.0 are already the Linux default. The tagged 3.1.0 source still has a separate `gtk3` legacy build. It excludes `purego` from the cgo backends, and the experimental Linux GTK4 backend selects `linux && purego && !gtk3 && !android && !server`. The production target keeps cgo and the GTK4 system libraries installed in `.github/workflows/ci.yml:48` and `.github/workflows/release.yml:115`. Inkwell's own GTK path uses `!gtk3` in `cmd/inkwell/close_view_gtk.go:1` and resolves GTK4/WebKit symbols. The alternate path starts at `cmd/inkwell/close_view_wails.go:1`.
