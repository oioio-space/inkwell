# EX0b2: the command palette, its ranker and the shortcuts window

Rigour: standard. Gate `gates/EX0b2.toml`, witnesses `gates/EX0b2/WITNESSES.md`, review `gates/EX0b2/REVIEW.md`. Built
on EX0b1's registry (`frontend/src/extensions/`: `run()`, `availability()`, `chordsOf()`, `renderChord()`, the binding
resolution with `mine` and `replaced`, `keytables.ts`). Closes P20 with EX0b1; applies spec §4.24, §4.26, §8.2 (rows
« Palette », « Raccourcis »), UX1 rule 48, ux-principles rule 3, architecture §15.4 (palette ≤ 50 ms with 1 000
commands, 0 extension call to draw). Out: « Aller au fichier » (Ctrl+P, its own block); editing one's shortcuts
(UX1-5); English labels matched in French (cut on review); typo tolerance → EX0b3 (judged from OBS1's count of queries
with no result; never a scattered-letter class).

## Prior art (read 2026-11-25) and the choice

- **VS Code quick open** (`fuzzyScorer.ts`): an O(m·n) matrix, +1 a match, +6/+12/+18 for a run, +8 at the start,
  +4/+5 after a separator, +2 camel case; scattered letters allowed. Its **command palette** does not use it:
  `commandsQuickAccess.ts` keeps a command only if the query is a contiguous substring or matches word starts, then
  sorts recent first (LRU of 50, `workbench.commandPalette.history`), then by label ([scorer](https://github.com/microsoft/vscode/blob/main/src/vs/base/common/fuzzyScorer.ts),
  [palette](https://github.com/microsoft/vscode/blob/main/src/vs/platform/quickinput/browser/commandsQuickAccess.ts)).
- **Zed** (`command_palette.rs`): nucleo fuzzy matching; used commands first by (last run, count) with or without a
  query; only palette runs count ([source](https://github.com/zed-industries/zed/blob/main/crates/command_palette/src/command_palette.rs)).
- **Sublime Text**: scattered subsequence with bonuses and penalties ([reverse-engineered](https://www.forrestthewoods.com/blog/reverse_engineering_sublime_texts_fuzzy_match/));
  fzf: V1 greedy O(n), V2 O(n·m) ([algo.go](https://github.com/junegunn/fzf/blob/master/src/algo/algo.go)).
- **GNOME**: `GtkShortcutsWindow` deprecated since GTK 4.18; libadwaita 1.8's `AdwShortcutsDialog`: sections of items,
  each an accelerator or an action whose accelerator it shows, drawn by `AdwShortcutLabel` ([GTK](https://docs.gtk.org/gtk4/class.ShortcutsWindow.html),
  [Adw](https://gnome.pages.gitlab.gnome.org/libadwaita/doc/main/class.ShortcutsDialog.html)); Ctrl+? ([HIG](https://developer.gnome.org/hig/guidelines/keyboard.html)).
  APG editable combobox with a listbox popup ([APG](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)).

**Choice: ordered match classes, each checked in one counted linear pass.** A continuous score (VS Code, Sublime, fzf,
nucleo) almost never ties, so rule 48's recency tie-break would never act, and it costs O(m·n) per text. Scattered
letters match too much in French labels (« pr » is in a third of them); VS Code's own palette refuses them. Recency
before quality with a query (VS Code, Zed) is what rule 48 rejects. The window follows `AdwShortcutsDialog`, plus a
search (§4.26), from the registry and `keytables.ts` only (§15.4: no extension call to draw).

## 1. Design

- **Text** (`ui/command/fold.ts`): NFKD (« … » → « ... »), marks removed, lower case, œ → oe, æ → ae, ß → ss, « » and
  quotes removed, spaces collapsed. Word separators: space ' ’ - / : ( ). Labels and keywords are folded once per
  registry and language. Built-in `keywords` are i18n keys read by `t()` in the language; a third-party keyword is a
  literal, matched in every language. A query is folded, cut at 64 characters and 8 words.
- **Classes** (`ui/command/rank.ts`, explicit loops only, every comparison counted in `rankStats`), best first: (1) the
  label equals the query; (2) the label starts with it; (3) each query word starts a word of the label, in order, label
  words skipped allowed, each used once (greedy, one pass); (4) one piece inside the label (KMP); (5) as (2)–(3) on a
  keyword; (6) as (4) on a keyword. Nothing else matches.
- **Order** (rule 48): available before unavailable; then, with a query, the class, then recency, then the label
  (`Intl.Collator` of the language); without a query, recency, then the label.
- **Availability** is computed once at opening, against the **target**: the element focused before opening, or, when it
  is detached or a menu item, the menu's return target (the last focused surface). It is cached while the palette is
  open (one `evalWhen` per command per opening). Every listed command runs on that target or says why: a `when` needs an
  `unavailable` (validator, vector `missing-key.command-when-unavailable`); built-ins gain what the census found
  missing: `app.return` its `when: canReturn` and reason (it had the condition on its menu item only), and the eight
  surface-only commands (`app.undo`, `-redo`, `app.find`, `-replace`, `-find-next`, `-find-previous`, `app.next-change`,
  `-previous-change`) a reason shown when the target's surface does not declare them.
- **Recents**: this device (`inkwell.palette.recent`, read and written in `try`), the last 50 commands run from the
  palette, the latest first; an unknown id is dropped, a malformed value reads as none.
- **Palette** (`ui/command/Palette.svelte`, modal `dialog` `medium` at the top, Adwaita tokens): field
  `role="combobox"`, `aria-expanded`, `aria-controls`, `aria-autocomplete="list"`, `aria-activedescendant`; list
  `role="listbox"`, rows `role="option"` + `aria-selected`: label, chord of this system, category. A window of at most 50
  rows around the active row; ↑ ↓ PageUp PageDown reach every match. Rows take no focus (`mousedown` prevented). A live
  `status` region **inside the dialog** says the count (« 62 commandes », « Aucune commande »), debounced 300 ms. An
  unavailable row is `aria-disabled`, its reason in an element tied by `aria-describedby`; Enter or a click on it
  announces the reason and runs nothing, the palette stays open. Enter on an available row closes, gives the focus back
  to the target, records the recent, then `run(id, target)`. Escape gives the focus back and runs nothing. `app.palette`
  is not listed. While a dialog of this block is open, its own command focuses its field and selects the query; the
  other one replaces it (one dialog at a time).
- **Shortcuts window** (`ui/command/ShortcutsWindow.svelte`, modal `dialog` `large`): one section per category in
  `CATEGORIES` order, a row per command with a chord in force on this system (all its chords, `renderChord`); then an
  « Écrire » section: the `keytables.ts` entries that carry a label key (editor and grid: select all, indent, edit a
  cell, open a cell's list…), never bare cursor movement. A delegated or widget chord is marked « géré par le système »
  or « géré par l'éditeur »; hers « personnalisé »; a default she replaced is absent. A search filters with the same
  fold and classes. Escape gives the focus back.
- **Entry points** (`ext/app`): `app.palette` Ctrl+Shift+p, `Meta+Shift+p`, Ctrl+Shift+p (`window`), main menu
  `project` 90 « Rechercher une commande… »; `app.shortcuts` Ctrl+?, `Alt+Meta+/`, Ctrl+? (shown « Ctrl+Maj+? »), main
  menu `app` 15 « Raccourcis clavier ». Both components are dynamic imports loaded at first run, once.

## 2. Rules (test titles in the gate; each mutant caught by that title only)

| Rule | What | Mutant |
|---|---|---|
| P-1 | fold: accents, case, NFKD « … », « » quotes, ligatures, the separators; folded once per registry and language, 0 per keystroke | MP1 marks kept |
| P-2 | the six classes (≥ 24 rows): « pan gau », « panneau gauche » (word skipped), « gau pan » none, « pdg » none, « l’aperçu » after ’; built-in keyword by `t()`, a third-party literal in every language | MP2 words matched in any order |
| P-3 | available first, then class, recency, label; no query: recents first; a recent weaker match below a better one | MP3 recency before class |
| P-4 | recents: palette runs only, moved to the front, ≤ 50, unknown dropped, malformed or throwing storage = none | MP4 appended, not moved |
| P-5 | availability against the target, once per opening: an editor-only command opened from the editor is available; a greyed row has its reason by `aria-describedby`; Enter and click announce it and run nothing; every built-in `when` has a reason, a surface-only command has one; `evalWhen` ≤ N per opening, 0 per keystroke | MP5 availability read from the palette's field |
| P-6 | APG attributes, `aria-activedescendant` follows the keys; the 50-row window follows the active row, PageDown reaches the last of 120; status inside the dialog, debounced, « Aucune commande » | MP6 rows cut at the first 50 |
| P-7 | Enter: focus back to the target, then `run(id, target)` (a recorder); from a menu item or a detached opener the target is the menu's return target; `mousedown` keeps the field focused; Escape runs nothing; own and other command while open | MP7 the opener used even when detached |
| P-8 | 1 000 seeded synthetic commands; queries « a », « pan gau », « de la page » and 64 characters « a…ab »: comparisons ≤ 4 × words × Σ(label + keyword lengths), selection ≤ 12 × N, ≤ 50 rows, 0 folds | MP8 naive substring search |
| P-9 | shortcuts window per system: every chord in force once, in category sections; « Écrire » holds the labelled widget keys only, marked; hers marked, a replaced default absent; search filters | MP9 her bindings unmarked |
| P-10 | entry points: chords, menu items, lazy loading (none at start, once on two runs); `app.shortcuts` opens the window | MP10 shortcuts opens the palette |

`ranker-lint` (gate): `rank.ts` holds no `includes`, `indexOf`, `startsWith`, `endsWith`, `search`, `match`, `RegExp` or
regular-expression literal, so no comparison escapes the counter.

End to end (`frontend/e2e/ex0b2.spec.ts`): **EX0b2-E1** Ctrl+Shift+P in the text opens the palette, « gras » puts
« Gras » first, Enter bolds the selection with the focus back in the text; main menu › « Rechercher une commande… »,
« gras », Enter bolds again; reopened, « Gras » is first without a query; « réglages » finds « Préférences »; a
presentation command in a Markdown file is greyed and Enter announces its reason; Escape gives the focus back.
**EX0b2-E2 PERF-PALETTE**: the e2e build (`VITE_E2E_OBSERVE`) adds a data-only fixture extension of 1 000 commands
(absent from production, criterion `chunks`); marks `ex0b2:palette-open` (keydown → frame after the rows are drawn) and
`ex0b2:palette-filter` (input → that frame); first open ≤ 200 ms; 1 warm-up and 10 opens, slowest ≤ 50 ms; 10
one-letter queries, slowest ≤ 50 ms; Chromium and WebKit. **EX0b2-E3** Ctrl+? opens the window with « Gras » and its
chord, the « Écrire » section, a binding stored in `inkwell.keybindings` marked, « zoom » filters. Replayed: EX0b1-E1,
EX0b1-E2, UI-02, UI-03, SAV-03b.

## 3. Performance and gate

The ranker's cost is proven by count (P-8, `ranker-lint`) and the 1 000-command budget timed in both engines (E2).
Start: PERF-START paired (ADR 0038), a regression guard. Gate (max 45 min): `docs`, `no-hard-keys` (EX0b1's,
replayed), `ranker-lint`, `chunks`, `frontend`, `mutants`, `e2e`, `e2e-webkit`, `perf-start`, `simplify-report`.
